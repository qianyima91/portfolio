# 为AI作品添加PDF作品集

更新：2026-10-27。上传和保存仍在本机编辑器进行；保存后双击“发布网站.cmd”推送GitHub，由Pages自动更新同一个公开网址。公开页面不提供上传入口。

1. 打开本地编辑器，选择“AI创作”，找到“幸福感侦察报告”。也可以点击卡片下方的“上传PDF作品集”入口直接进入对应作品。
2. 在“PDF作品集”区域点击“上传 / 替换PDF”，选择PDF文件，最大30MB。
3. 上传后显示原文件名，可点击“查看PDF”检查，随后点击顶部“保存到网站”。
4. 刷新展示页，卡片下方会出现带文档小图标的“查看作品集 PDF”，新标签页打开PDF。原播放/体验入口保持独立。
5. “移除入口”清空该作品的PDF关联，保存后入口隐藏；保留原上传文件，不擅自删除原件。

也可在“PDF作品集路径或网址”填写公开PDF链接。其他AI作品同样支持可选PDF，不上传时不会在正式页面显示空按钮。“幸福感侦察报告”在制作预览中保留上传提示，方便补齐。

上传文件保存于assets/uploads/portfolios/，使用独立文件名，原始文件名仅作为编辑器中的说明保留。公开构建仅包含当前关联的PDF资源与内容关联；移除关联后下次构建不再复制该PDF，原文件仍保留在本机和Git历史中。

开发检查：`node scripts/verify-pdf-upload.mjs`会向本机服务上传原始大纲的临时副本，核对内容完整性、内联响应、伪PDF拒绝与同源限制，结束后仅移除本次测试副本，不修改网站项目关联。
