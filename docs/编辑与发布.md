# 修改如何更新到公开网站

2026-10-27，GitHub和公开展示已接通；编辑仍在本机进行。

1. 双击网站文件夹中的`编辑作品集.cmd`，自动打开 http://127.0.0.1:4173/admin/ 。已有服务时直接使用，不重复启动。
2. 修改后点右上角**保存到本地**（原名“保存到网站”）。此时只更新本机文件与本地预览，并自动备份；公开网址尚未更新。
3. 双击同目录中的**发布网站.cmd**。它会检查、生成手机图片、提交并推送GitHub。窗口出现“已推送GitHub”表示上传完成，部署仍需等待。
4. 在编辑器左侧点击**查看发布进度**，最新一条`Publish portfolio`显示绿色成功后，刷新 https://qianyima91.github.io/portfolio/ 。

`编辑作品集.cmd`用于打开编辑器；`启动网站.cmd`是原来的服务启动方式；**只有`发布网站.cmd`会将本机修改提交到GitHub并触发上线**。

如果发布窗口报错，保留错误提示；未发布成功前，线上仍显示上一次成功版本，本机保存内容保留。不要通过重复刷新公开网址判断本机是否保存。

当前电脑的系统代理如果启用且使用localhost/127.0.0.1端口，发布脚本会在Git没有显式代理配置时，仅为本次推送使用该代理，不修改系统或全局Git设置。
