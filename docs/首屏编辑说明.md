# 首屏字体、排版与数据编辑

更新：2026-10-27。编辑器保存到本地网站文件；GitHub仓库已接通，双击“发布网站.cmd”后由Pages自动更新公开展示页。公开网址不提供编辑接口。

1. 在网站目录运行`node scripts/server.mjs`，或双击`启动网站.cmd`。
2. 打开http://127.0.0.1:4173/admin/，选择“首屏字体与排版”。
3. 分别展开姓名、岗位、学校与身份、三个关键词，修改字体、电脑/手机字号、字重、字距、行高、颜色和倾斜。字体采用本机已安装字体及回退，不自动上传系统字体。
   英文副标题也可独立编辑，默认PRODUCT OPERATIONS；留空隐藏，岗位与英文间距在“位置与间距”中调整。
4. “位置与间距”调整电脑版缩进、标题位置和两组间距；手机保持独立布局。
5. “首页数据”逐组编辑数字、名称、说明。最后一组当前为`2.5h→35min / 单篇多模态内容 / 自建AI工作台提效4.3倍`。
6. 右侧即时预览可切换电脑/手机；点击顶部“保存到网站”后，刷新独立页面查看。
7. 需要更新公开网站时，双击网站目录的“发布网站.cmd”，等待GitHub Actions部署成功。本地展示页底部固定提供“编辑内容”，不依赖“显示占位”开关；“查看公开效果”隐藏此入口。

“恢复默认样式”仅还原四组文字与布局设置，不重置数据和文案。每次保存前备份旧内容到docs/backups/。右侧未保存预览不等于正式文件已改变。

展示交互：悬浮或键盘聚焦某组数据，数字、名称与说明一起变紫并放大。桌面四列，手机两列，平台调用说明保留“5—7月平台累计调用”。
